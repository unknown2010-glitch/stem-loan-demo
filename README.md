STEM Educational Loan True-Cost Simulator — Buyer Guide
======================================================

Thank you for purchasing this template! Everything runs in a single,
self-contained HTML file (no backend, database, or npm setup needed).

1. HOW TO PREVIEW
- Open "stem_loan_simulator.html" in Chrome, Safari, or Edge.

2. HOW TO CUSTOMIZE (1-MINUTE SETUP)
- Open "stem_loan_simulator.html" in any text or code editor (Notepad,
  VS Code, or an Android text editor).
- Scroll to the <script> section and find "SIMULATOR_CONFIG" near the top:
  * brandTitle: Change to your website or agency name
  * brandSubtitle: Edit the tagline shown under the title
  * currencySymbol & locale: Default is '₹' / 'en-IN' (switch to '$' / 'en-US' if needed)
  * ctaLabel & ctaUrl: Add a button label (e.g., "Book Free Counseling")
    and your WhatsApp/Calendly/website link to display a header CTA button.
- Save the file and refresh your browser.

3. HOW TO PUBLISH ONLINE FOR FREE
- Option A (Easiest): Drag and drop "stem_loan_simulator.html" onto
  Netlify Drop (app.netlify.com/drop) to get a live link in 10 seconds.
- Option B (GitHub Pages): Upload the file as "index.html" to a public
  GitHub repository and enable GitHub Pages in Settings.
- Option C (Embed on WordPress/Wix/Framer): Upload the HTML file to your
  hosting/Netlify and embed it using an <iframe> tag.
